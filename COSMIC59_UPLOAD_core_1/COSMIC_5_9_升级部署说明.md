# COSMIC 5.9 部署说明
本包基于 5.8.3，保留原命盘计算与 OpenAI 生图接口。
新增流年健康、30岁以下学业、事业、正财、偏财、破财、感情、亲情、友情、贵人、人际摩擦分析，以及穿衣、饮食、十二时辰作息和节气建议。
新增内容为依据排盘结果组合的文化解读与生活建议，不是确定性预测；年龄按流年减出生年近似判断。
将 web/index.html 上传到 GitHub 仓库现有部署文件夹下的 web/index.html，不要上传到仓库根目录。其余文件保持原有位置。Render 自动部署后检查 Live。
OpenAI API Key 只配置在 Render Environment，不要上传 GitHub。图片生成仍需独立 API 额度。
