# COSMIC 5.8.1 公网部署包

此包已添加 Render Docker 部署配置，服务监听 `0.0.0.0` 并自动读取平台 `PORT` 环境变量；健康检查为 `/health`。应用无需安装第三方 Python 包。

## 一次部署、以后自动更新

1. 把本目录完整上传到你自己的 GitHub 私有仓库（不要只上传 index.html；需要包含 app、web/assets、assets、tests 等目录）。
2. 登录 Render，选择 **New + → Web Service**，连接这个 GitHub 仓库。
3. Runtime 选 Docker（有 Dockerfile 时通常可自动识别），部署分支选 `main`，开启 Auto-Deploy。
4. 创建服务后等待首次部署成功。Render 会提供固定的 `https://<服务名>.onrender.com` 公网地址；打开 `https://<服务名>.onrender.com/health` 应返回 `ok: true`。
5. 以后更新代码只需推送到 GitHub 的部署分支，Render 会自动重新部署，不用每次下载或安装 ZIP。

## 重要
- 当前 ZIP 是部署源代码包，不是已经发布的公网网站；公网网址必须由你登录自己的托管账号创建后生成。
- 若选择免费实例，服务可能休眠，首次访问会等待唤醒；需要稳定响应可选择常驻实例。
- 上线后先测试：主页 `/`、健康检查 `/health`、输入不同出生信息并点击“开始分析”、本命与流年手串图片和地域搜索。
- 不要把账号密码、访问令牌写进代码或发到聊天中。
